# Lessons Learned

- **[L-001] DeprecatedEnv on Gymnasium 1.0+**: Calling `gym.make("Taxi-v3")` in modern Gymnasium raises `DeprecatedEnv`. Solution: Use an adapter in `src/env_utils.py` that defaults to `Taxi-v4` while honoring the exact Taxi-v3 specification.
- **[L-002] Analytical Invariants**: In Gymnasium Taxi, any successful episode with zero illegal actions satisfies `total_reward == 21 - steps`. Verifying this invariant on clean traces ensures step rewards (-1 per move, +20 on dropoff) are tracked accurately without off-by-one discrepancies.
- **[L-003] Epsilon Tie-Breaking**: When the Q-table is initialized to all zeros, a standard `argmax` always selects action 0 (move south), causing severe spatial exploration bias. Vectorized random tie-breaking among all maximal values ensures uniform exploration across all available actions during early learning.
- **[L-004] High Learning Rates in Deterministic MDPs**: In environments with deterministic transitions like Gymnasium Taxi, higher learning rates ($\alpha \ge 0.5$, optimally $\alpha = 0.7$) achieve dramatic convergence acceleration (~800 episodes vs ~2,300 for $\alpha=0.1$) without risk of divergence or oscillation, because deterministic Bellman targets do not suffer from stochastic transition variance. Additionally, Python multiprocessing on Windows requires module top-level worker functions rather than nested functions or lambdas due to pickle serialization limitations.
- **[L-005] Non-Parametric Bootstrap CI and Headless Animation Rendering**: In reinforcement learning benchmarking where test reward distributions may exhibit slight skew or multi-modality due to grid distance variations, empirical bootstrap confidence intervals (e.g. 1,000 resamples) provide robust statistical error bounds without assuming normality. Furthermore, in headless CI/CD environments, configuring `matplotlib.use('Agg')` and utilizing Pillow's native in-memory frame buffer rendering avoids external native graphics dependencies while reliably producing high-quality animated GIFs.
