# Glossary

- **Bellman Equation**: Mathematical expression decomposing value function into immediate reward plus discounted expected future return.
- **Epsilon-Greedy**: Exploration policy balancing random exploration ($\epsilon$) with exploitation ($1-\epsilon$).
- **Terminated**: Natural goal state reached (passenger dropped off).
- **Truncated**: Artificial step limit reached (200 steps).
- **Taxi-v4**: Modern Gymnasium registration for the discrete 500-state Taxi problem.
