# T-0002 — Tabular Q-Learning Agent & Training Loop
Backlog ref: REQ-003, REQ-004 · Sprint: 2 · Priority: MUST

## Intent
Implement the core reinforcement learning components: tabular `QLearningAgent` in `src/agent.py`, decay schedules in `src/schedules.py`, and the full training loop with periodic greedy validation and convergence detection in `src/train.py`.

## Scope / Out of scope
- **Scope**:
  - `src/agent.py`: `QLearningAgent` with shape `(500, 6)` Q-table, Bellman update, random tie-breaking greedy selection, and `.npy` save/load.
  - `src/schedules.py`: Multiplicative and linear epsilon decay schedules respecting floors.
  - `src/train.py`: Full training loop, CSV logging per episode, validation evaluation on fixed seeds (offset 5000), convergence tracking, and Q-table export.
  - Unit tests in `tests/test_agent.py`, `tests/test_schedules.py`, `tests/test_train.py`.
- **Out of scope**:
  - Multi-worker hyperparameter tuning (`src/tune.py`) and sweeps (deferred to `T-0003`).
  - 1,000 unseen test evaluation and publication plots (`src/evaluate.py`, `src/plots.py`, deferred to `T-0004`).

## Guidance
- Epsilon-greedy: with probability $\epsilon$ pick random action, else greedy action.
- When multiple actions share maximal Q-value, break ties uniformly at random using seeded generator.
- Cut off Bellman bootstrap strictly on `terminated`, NOT on `truncated` (step 200 timeout still bootstraps).
- Log training metrics to `results/training_log.csv`.
- Convergence detector: episode where validation reward stays $\ge 7.0$ for 3 consecutive evaluation cycles.

## Requirements
- `REQ-003`: From-scratch `QLearningAgent` with Q-table, Bellman update, tie-breaking greedy action, and decay schedules.
- `REQ-004`: Modular training loop with periodic validation, metrics logging (CSV), convergence detector, and model persistence.

## Acceptance
- `AC-003-a`: Given a transition $(s, a, r, s')$, when `terminated=True`, the target is $r$; when `truncated=True`, the target bootstraps $\gamma \max_{a'} Q(s', a')$.
- `AC-003-b`: Given equal max Q-values across multiple actions, `greedy_action` breaks ties uniformly at random rather than always selecting action 0.
- `AC-003-c`: Given epsilon schedules (multiplicative and linear), when evaluated over episode indices, epsilon decays monotonically to `epsilon_min`.
- `AC-004-a`: Given `train()`, each episode logs reward, steps, epsilon, illegal moves, and success to CSV.
- `AC-004-b`: Given periodic evaluation every $N$ episodes on validation seeds, when greedy reward $\ge 7.0$ for `convergence_patience` checks, convergence episode is logged.

## Risks / Notes
- Avoid bias on all-zero Q-table: uniform tie-breaking ensures equal probability across all actions on initialization.
- Periodic validation must use pure greedy policy ($\epsilon = 0$) and never mutate the Q-table.
