# T-0001 — Walking Skeleton & Environment Exploration
Backlog ref: REQ-001, REQ-002 · Sprint: 1 · Priority: MUST

## Intent
Establish the walking skeleton of the project: reproducible environment utilities, seeding, configuration loading with schema validation, state encode/decode invariant verification, and execution of the 1,000-episode random policy baseline saved to `results/baseline_random.json`.

## Scope / Out of scope
- **Scope**:
  - `requirements.txt` with pinned versions.
  - `config/default.yaml` baseline hyperparameter file.
  - `src/env_utils.py` with `make_env` (Taxi-v3/Taxi-v4 adapter), `get_seeded_rng`, `decode_state`, `encode_state`, and state round-trip check.
  - Baseline random rollout evaluating 1,000 episodes, saving metrics to `results/baseline_random.json`.
  - Comprehensive unit tests in `tests/test_env.py`.
- **Out of scope**:
  - Tabular Q-learning algorithm (`QLearningAgent`) or training loops (deferred to `T-0002`).
  - Hyperparameter tuning or visual plots (deferred to `T-0003`, `T-0004`).

## Guidance
- Support Gymnasium 1.4.0 where `Taxi-v4` is the active environment while maintaining full backwards compatibility.
- Use `np.random.default_rng(seed)` for all stochastic sources.
- For the random policy baseline, compute and record: `mean_reward`, `std_reward`, `mean_steps`, `success_rate`, `truncation_rate`, and `illegal_action_count`.

## Requirements
- `REQ-001`: Reproducible package structure, dependencies, configuration loading (`config/default.yaml`), and seeding utilities.
- `REQ-002`: Environment exploration, state decode/encode verification, and seeded random-policy baseline (1,000 episodes).

## Acceptance
- `AC-001-a`: Given `config/default.yaml`, when loaded with schema validation, then all required training and evaluation parameters are parsed with correct types.
- `AC-001-b`: Given a seed integer, when initialized via `src/env_utils.py`, then a NumPy `Generator` is returned and Taxi environment reset produces repeatable observations.
- `AC-002-a`: Given the Taxi environment, when tested, states decode into `(taxi_row, taxi_col, pass_loc, dest)` and round-trip encode matches the original index for all 500 states.
- `AC-002-b`: Given a random policy evaluated over 1,000 episodes, then metrics are recorded to `results/baseline_random.json` with average reward $< -200$.
- `AC-002-c`: Given any successful episode with no illegal actions, the total reward strictly equals $21 - \text{steps}$.

## Risks / Notes
- Gymnasium deprecation warning on `Taxi-v3` resolved by `make_env` transparently falling back to `Taxi-v4`.
- Seed the environment only on the first reset for baseline rollouts to ensure varied but reproducible episodes.
